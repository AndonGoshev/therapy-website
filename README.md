# Терапевтичен Уебсайт

Модерен, визуално привлекателен уебсайт за психотерапевт, базиран в Пловдив, България. Сайтът е изграден с Eleventy (11ty), Nunjucks и Tailwind CSS.

## 🚀 Особености

- Модерен, успокояващ дизайн с топли цветове
- Напълно отзивчив и мобилно-първи подход
- Оптимизиран за достъпност
- Български език
- SEO оптимизация
- Бързо зареждане
- Лесна поддръжка и актуализация на съдържанието

## 🛠️ Технологии

- [Eleventy (11ty)](https://www.11ty.dev/) - Статичен генератор на сайтове
- [Nunjucks](https://mozilla.github.io/nunjucks/) - Шаблониращ език
- [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS framework
- [Google Fonts](https://fonts.google.com/) - Шрифтове (Inter, Lora)

## 📦 Инсталация

1. Клонирайте репозиторито:
```bash
git clone [repository-url]
cd therapy-website
```

2. Инсталирайте зависимостите:
```bash
npm install
```

3. Стартирайте сървъра за разработка:
```bash
npm start
```

Сайтът ще бъде достъпен на `http://localhost:8080`

## 🏗️ Строеж

За да създадете продукционна версия на сайта:

```bash
npm run build
```

Готовите файлове ще бъдат в директорията `_site`

## 📁 Структура на проекта

```
therapy-website/
├── src/
│   ├── _includes/     # Частични шаблони
│   ├── _layouts/      # Основни шаблони
│   ├── _data/         # Данни за сайта
│   ├── css/           # CSS файлове
│   ├── images/        # Изображения
│   ├── js/            # JavaScript файлове
│   └── *.njk         # Страници
├── _site/            # Готовата версия на сайта
├── .eleventy.js      # Конфигурация на Eleventy
├── tailwind.config.js # Конфигурация на Tailwind
└── package.json      # Зависимости и скриптове
```
